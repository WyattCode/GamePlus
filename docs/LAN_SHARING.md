# 局域网共享（主机加速）使用说明

Game+ 提供「局域网共享（主机加速）」功能：在 Game+ 加速运行期间，在本机的一个局域网 IPv4 地址上额外开启 HTTP 代理（可选 SOCKS5）入站，并把经过这些入站的流量转发到当前节点。Switch / PlayStation / Xbox 等主机支持在系统网络设置中填写「代理服务器」，填写后主机发出的 TCP 流量即可经由 Game+ 的节点转发。

## 它能做什么

- 主机的**商店、下载、登录、账号验证以及部分联机/API 接口**（只要主机把请求发往代理）会经过节点加速。
- 可选开启 SOCKS5 入站，供同一局域网内的电脑、手机等设备使用。
- 仅在 Game+ 正在加速时生效；停止加速后共享入站随之关闭。

## 它不能做什么（重要限制）

- **只转发 TCP**：主机通过 HTTP 代理发出的流量只有 TCP 会被转发。
- **游戏 UDP 对战流量、P2P 连接、语音聊天不会经过节点**：主机的对战流量通常不走代理，因此 NAT 类型不会改善，也不能降低对战延迟。
- 不能替代真正的「网关模式」。完整的网关模式需要把主机默认网关指向电脑、在电脑上做 IP 转发 + WinTUN 抓取转发流量 + NAT，目前**未实现**（见下文「为什么没有网关模式」）。

## 开启步骤

1. 打开 Game+ → 设置 → 「局域网共享（主机加速）」。
2. 选择**共享地址**（本机的一个局域网 IPv4，如 192.168.1.23）、HTTP 端口（默认 7899），可选填写 SOCKS5 端口、用户名/密码。
3. 在「允许的设备」中填写主机的局域网 IP 或网段（每行一条，必填，最多 32 条），例如 `192.168.1.50` 或 `192.168.1.0/24`。
4. 打开「开启局域网共享」开关并确认。首次开启时 Windows 防火墙可能弹窗，请选择「专用网络」并允许（Game+ **不会**自动添加防火墙规则）。
5. 在主机的网络设置中配置代理服务器（见下文），地址填共享地址，端口填 HTTP 端口；如设置了用户名/密码，主机上也需填写相同内容。
6. 在 Game+ 中开始加速后，共享即生效；加速页会显示「局域网共享中 · 地址:端口」。

### 主机上的代理设置路径（大致位置，因系统版本而异）

- **Switch**：设置 → 互联网 → 互联网设置 → 选择当前网络 → 更改设置 → 代理服务器设置 → 开启，填写服务器地址与端口。
- **PS4 / PS5**：设置 → 网络 → 设定互联网连接 → 选择网络 →（PS5：高级设定）→ 代理服务器 → 使用，填写地址与端口。
- **Xbox**：设置 → 常规 → 网络设置 → 高级设置 → 代理服务器，填写地址与端口。

## 安全模型

- **默认关闭**：不进行任何显式操作（开关 + 确认弹窗）不会开启任何局域网入站。
- **只绑定一个局域网地址**：入站只绑定到用户选择的本机私有 IPv4（10.x / 172.16–31.x / 192.168.x），绝不绑定 0.0.0.0、:: 或公网地址。
- **允许列表必填**：允许列表为空时无法开启；不在列表内的局域网设备会被路由规则直接阻断。
- **可选认证**：可设置用户名/密码（HTTP Basic / SOCKS 认证）。
- **端口限制**：端口范围 1024–65535，HTTP 与 SOCKS5 端口必须不同，且不能与本地 SOCKS 端口设置冲突。
- **不自动改防火墙**：Game+ 不会静默添加 Windows 防火墙规则，由 Windows 弹窗由用户决定。

## 为什么没有网关模式

让主机把默认网关指向电脑、由电脑转发全部流量（含 UDP）需要：修改 Windows IP 转发设置、用 WinTUN 抓取**转发**的流量并做 NAT。这会把电脑变成一台路由器，显著增加误配置风险（例如把整个网络的上网路径改坏、把不该转发的流量暴露给节点），因此当前版本只提供安全的「HTTP 代理共享」模式。

## 常见问题排查

- **主机无法上网 / 无法连接代理**：确认 Game+ 正在加速；确认主机填写的地址、端口与设置页一致；确认主机 IP 在允许列表内；检查 Windows 防火墙是否放行了 Game+（专用网络）。
- **商店能加速但游戏对战没变化**：这是预期行为——对战 UDP 流量不经过代理。
- **提示端口冲突**：更换 HTTP/SOCKS5 端口，确保两者不同且不与本地 SOCKS 端口相同。
- **找不到局域网地址**：确认电脑已通过网线或 Wi-Fi 连入局域网，点击「刷新」重新获取。
